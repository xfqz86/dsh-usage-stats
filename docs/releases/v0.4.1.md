## 这是一轮修复，没有新功能

主要把概览页额度磁贴的几种「看起来不对」都修正了：

- OpenCode Go 没开通订阅时，此前误提示「未配置 API Key」；现在如实显示「未开通 OpenCode Go 订阅」，和 Z.ai 的空态一致，未订阅也能手动刷新、会显示更新时间。
- 磁贴在数据还在加载的一瞬间不再闪现「未配置 API Key」，而是显示「加载中…」；查询失败时改为醒目的告警样式卡片。
- 三块额度磁贴（OpenCode Go / Z.ai / DeepSeek）现在常驻「立即刷新」按钮和「更新于」时间，随时可以手动重查、核对接口查询时间。
- 「立即刷新」变成了真正的强制刷新：此前 3 分钟内点击会直接返回缓存结果、看起来毫无变化；现在点击即重新请求官方接口（自动轮询的间隔限制不变）。
- 侧边栏展开时，额度行在未订阅、未配置 Key 时直接显示「未订阅」「未配置 Key」，不再只是一个无信息的横杠；折叠时仍显示横杠，悬浮可看完整说明。

其他修正：

- 会话页的「最近活跃」按自然日区分：「今天」显示「今天」、「昨天」显示「昨天 HH:MM」，不再把昨天凌晨的会话在第二天白天仍显示成今天。
- 设置页的抓取间隔输入框不再被首屏默认值覆盖，避免了没动过它却在失焦时把默认值误存回去。
- 概览页左列「今日 / 总计」磁贴的高度与热力图上下边缘对齐，不再悬浮留白。
