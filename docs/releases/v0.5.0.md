## 这版：三个页面都能点开看明细，设置也能整份搬走

- **会话页也能点开看明细**：主会话那一行点「明细」，就能把这条会话的用量按日期、按模型摊开看，子会话（子代理）的用量一并计入，数字与所点那一行一致。
- **模型页、日期页也各有明细**：模型页点「明细」看这块模型每天用了多少、花在哪些会话上，数字跟着所选时间范围；日期页点「明细」看某一天分别花在哪些会话、哪些模型上。
- **设置可以导出、导入**：设置页新增「配置迁移」，把当前偏好生成一串配置串复制走，在别的机器或 profile 里粘贴即整份还原。
- **会话 ID 徽标回到标题右侧第一位**：新版 dsh 的「用应用打开」按钮与 id 徽标抢同一个位置，id 被挤到了后面；现在固定在标题右侧最左，悬停复制照旧。
- 本次无统计口径变化，历史数据不受影响。

## 升级提醒

更新版本后请重启一次 dsh，再刷新浏览器页面——这一版新增了服务端接口，只刷新页面看不到新功能。
