## dsh-usage-stats 第一个版本

在侧边栏底部常驻「今日用量」徽章：宽列显示数字，折叠成一枚小圆钮也看得到；点开是完整的统计面板。

## 面板里有什么

- **概览**：总用量、今日用量、OpenCode Go 额度卡与最近 26 周热力图。
- **日期**：每日用量趋势，可切换时间范围。
- **会话**：每个会话的用量明细，支持按子代理折叠、排序和分页。
- **模型**：按模型与供应商拆分的用量、占比与趋势。
- **设置**：重建 / 清零统计与偏好项。

## 统计怎么来

安装后第一次打开会自动把 dsh 的全部历史会话统计一遍，之后新对话实时累计，重启 dsh 也不丢。

## OpenCode Go 额度

概览页与侧边栏可看 OpenCode Go 的滚动 5 小时 / 本周 / 本月剩余额度；设置里可以开关显示、调整抓取间隔。
