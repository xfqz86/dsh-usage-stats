## DeepSeek 余额监控

概览页、侧边栏与设置页可以看 DeepSeek 账户余额：按币种展示余额与可用状态。在 dsh 凭据中心配好 `DEEPSEEK_API_KEY`，设置页打开开关即可，抓取间隔可调。

## Z.ai 额度监控

同样新增 Z.ai 额度卡：滚动 5 小时窗口、本周额度与每月 Web 搜索次数。凭据支持 `ZAI_API_KEY` 或 `ZAI_CODING_CN_API_KEY`，接入方式与上面一致。
